## Real AutoCAD export evidence

`test-results/autocad-disposable-3813ad7d/` contains the disposable drawing, plot script, console log, PDF and rendered `preview.png`. AutoCAD 2025 Core Console exited 0. The A4 PDF renders the complete test rectangle and two circles; it is not blank. Source was a copy of the factory template, never the user's open business drawing.

Poppler reported metadata stream-length warnings while successfully rendering the page. This verifies the real AutoCAD export engine. It does not claim GUI application-ready detection or that this exact PDF travelled through the in-app capture workflow; the latter is independently covered by the P4C disposable browser test. An attempted interaction with the unrelated open drawing was rejected by automatic review and was not executed; the isolated export replaced that unsafe approach.

## Scope of acceptance

The Windows review package is separate from the earlier `approved-ui-review` package. Do not use that old executable as evidence for this delivery. Microsoft tenant SSO/deployment, live backup restore, all possible user-data combinations, and pixel-identical PDF/XLSX charts are not claimed. PDF/XLSX share authoritative values and output registration; their layouts differ. Large-bundle and default executable-icon build warnings remain packaging notes, not hidden failures.
